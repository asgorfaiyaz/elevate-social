# Elevate Social

Elevate Social is a community event platform that helps people organize and join local service activities.

**Live site:** [Visit Elevate Social](https://elevate-social-asgorfaiyaz.vercel.app/)

## Features

- Browse upcoming community events and filter them by title or event type.
- View event details without signing in.
- Create an account and sign in to join events.
- Check whether you have joined an event and view your joined events.
- Create, edit, and delete events you organize from your private management page.
- Find recent upcoming events and see event dates in a readable format.
- Switch between light and dark themes.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The app uses a separate events API and authentication service. Configure the required environment variables in `.env.local` before running it; do not commit secrets.
